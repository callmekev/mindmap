# 輕量思維導圖

一個零構建的網頁思維導圖工具。基於開源引擎 [mind-elixir](https://github.com/SSShooter/mind-elixir-core)（MIT協議，v5.15.1），只保留你需要的功能：文字節點、拖拽、插入小圖片、插入連結、本地自動保存、JSON導出/導入。

**v3更新**：修復兩個問題——(1) 畫布高度計算錯誤導致只顯示半屏（CSS絕對定位與庫內建`height:100%`衝突，已改用flex佈局）；(2) 新增剪貼簿直接貼上圖片支持（點選節點後按 `Ctrl+V`/`Cmd+V`，不必再走「插入圖片」按鈕選文件）。

## 這個工具能做到 / 做不到什麼

**能做到**：
- 文字節點編輯、自由拖拽、右鍵選單
- 插入圖片（自動壓縮到最長邊480px以內再保存，避免瀏覽器存儲被撐爆）
- 插入/編輯連結
- 每次操作後自動保存到瀏覽器 `localStorage`，刷新頁面不丟失
- 導出成 `.json` 文件備份，之後可以導入回來

**做不到 / 需要你注意**：
- ❌ 沒有多設備同步——數據存在單一瀏覽器的 `localStorage` 裡，換瀏覽器/換電腦/清瀏覽器數據都會導致本地存檔消失（**所以務必養成定期點「導出JSON」備份的習慣**）
- ❌ 不支持導出 XMind / FreeMind 格式（如果之後需要，這是另一個功能，需要另外加開發）
- ⚠️ `localStorage` 一般有 5-10MB 上限，插了太多大圖片可能會存滿導致自動保存失敗（工具會明確報錯提示，不會靜默丟數據）

## 部署到 GitHub Pages（幾分鐘搞定）

1. 在 GitHub 新建一個倉庫（比如叫 `my-mindmap`），Public 或 Private 都行
2. 把 `index.html` **連同整個 `vendor/` 資料夾**（裡面3個文件：`MindElixir.js`、`MindElixir.css`、`i18n.js`）一起上傳到倉庫根目錄，保持相對路徑結構不變（`vendor/` 要和 `index.html` 在同一層）
   - 網頁上傳：直接把 `index.html` 和 `vendor` 資料夾一起拖進 GitHub 網頁的上傳區
   - 或用 git：`git add . && git commit -m "init" && git push`
3. 倉庫 → **Settings → Pages**
4. **Source** 選 `Deploy from a branch`，**Branch** 選 `main`（或你的預設分支）+ 目錄選 `/ (root)`，保存
5. 等 1-2 分鐘，GitHub 會給你一個網址，形如 `https://<你的用戶名>.github.io/my-mindmap/`，打開就能用

> 如果你的倉庫是 Private，GitHub Pages 免費版通常仍可正常訪問生成的網址（網址本身不設密碼保護），但這代表任何拿到網址的人都能打開這個頁面。如果你的思維導圖內容比較私密，建議之後追加一層訪問密碼（目前版本沒做，需要的話告訴我再加）。

## ⚠️ 我沒能在自己的沙盒環境裡做「打開瀏覽器完整跑一遍」的端到端測試

我嘗試在沙盒裡裝無頭瀏覽器（Playwright）親自跑一次點擊測試，但沙盒的網絡白名單連瀏覽器安裝包本身都下載不了，這條路走不通。已經做的驗證：
- 用 `npm install` 把真實的 `mind-elixir@5.15.1` 包下載下來，逐個核對了文件路徑、版本號、API簽名（`getData`/`refresh`/`reshapeNode`/`bus.addListener` 等）都確實存在
- 用 `node --check` 驗證了內嵌JS語法沒有錯誤
- 檢查了 `vendor/` 三個文件內部沒有任何硬編碼的外部網絡請求（只有標準XML命名空間字符串），確認自包含、可離線運行
- 交叉核對官方文檔確認了模組引用方式的標準用法

但**沒有**做過"真的在瀏覽器裡打開、點一遍每個按鈕"這一步，這是誠實告知的限制。所以請你部署後務必按下面清單自己測一遍，如果有任何報錯，把瀏覽器控制台（F12 → Console）裡的紅色錯誤信息發給我，我來排查修復。

## Verify 清單（部署後請照做）

1. **打開頁面**：能看到頂部工具列 + 中間一個「新主題」節點，右上角狀態列顯示「初始化完成」
   - 如果空白/報錯 → 按F12開控制台看報錯信息
2. **建節點**：雙擊/右鍵新建幾個子節點，拖拽調整位置
3. **刷新頁面**：剛才建的節點應該還在（驗證自動保存生效）
4. **插入圖片（按鈕方式）**：點選一個節點 → 點「插入圖片」→ 選一張圖 → 節點上應該出現縮略圖
4b. **插入圖片（貼上方式）**：先點選一個節點，複製一張圖片（比如截圖到剪貼簿），直接按 `Ctrl+V`（Mac用 `Cmd+V`）→ 應該和按鈕方式一樣直接插入
5. **插入連結**：點選一個節點 → 點「插入/編輯連結」→ 輸入一個網址，比如 `https://github.com`
6. **導出JSON**：點「導出 JSON」→ 應該下載一個 `mindmap-xxxx.json` 文件
7. **測試恢復能力**：開瀏覽器隱私/無痕視窗打開同一個網址（模擬"換瀏覽器/清空數據"）→ 應該是全新的「新主題」→ 點「導入 JSON」選剛才導出的文件 → 內容應該完整恢復（含圖片和連結）

全部通過 = 可以放心長期使用。任何一步不對，把具體是哪一步、控制台什麼報錯告訴我。
